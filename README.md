# Bryan Segovia | Quantitative Finance Portfolio

Economics & Finance student at UPC (Lima, Peru) specializing in quantitative investment analysis, econometric modeling, and financial data engineering. Currently seeking internship opportunities in investments, portfolio management, and financial research.

## Projects

### [01 - Fixed Income Valuation & Risk Modeling](./01-fixed-income-valuation/src)
Bond pricing models, duration/convexity analysis, and yield curve scenarios using Python. Simulated interest rate shocks and their impact on fixed income portfolios. Includes unit tests and Price-Yield curve visualization.

### [02 - Credit Risk Analysis: Formality & Financial Access](./02-credit-risk-formalidad/code)
Causal impact of labor formality on financial access using simulated ENAHO data (35,000 obs). Potential outcomes framework with correlated errors (ρ=0.6). Bivariate Probit recovers true latent parameter, PSM estimates ATT, Rosenbaum bounds test sensitivity to unobserved heterogeneity.

### [03 - Financial Analysis & FP&A Projection (Alicorp)](./03-financial-analysis-fpa-alicorp)
Automated financial analysis pipeline in R using simulated data based on Peruvian consumer sector trends. Extracts historical financial statements, calculates profitability ratios, and projects the Income Statement for 3 years under stress scenarios (pessimistic/base/optimistic) anchored on historical CAGR. Outputs a structured Excel deliverable for financial committees.
